# آدم — موظف مبيعات ذكي على واتساب لشركة تأجير السيارات

بوت يرد على الزبائن في واتساب كتابةً وعلى مدار الساعة، كأنه موظف مبيعات حقيقي:

- يحكي **عربي أبيض، إنجليزي، تركي** حسب لغة الزبون
- يقرأ **الصور وملفات PDF** (رخصة، جواز، عرض سعر من منافس...)
- يرسل **صور السيارات**
- **يفاوض على السعر** ضمن حدود يفرضها الكود، فما بيقدر ينزل تحت الحد الأدنى أبداً
- يتأكد من **السيارات المتاحة** ويسجّل **طلب حجز** بينتظر تأكيد موظف
- يبعت **إشعارات** للإدارة: حجز جديد، عميل جاهز، شكوى، أو عميل بدو موظف بشري

البوت مبني على **Claude** (Anthropic) و**WhatsApp Cloud API** الرسمي من Meta.

---

## هيكل المشروع

| الملف | شو بيعمل |
|---|---|
| `knowledge/brain/` | **عقل آدم**: الشخصية، الشركة، خطوات البيع، التفاوض، الصلاحيات، خريطة الردود. شوف `knowledge/brain/README.md` |
| `knowledge/fleet.yaml` | السيارات والأسعار (تجريبي حالياً) |
| `knowledge/pricing.yaml` | خصومات المدة وقواعد التفاوض |
| `app/prompt.py` | شخصية آدم وأسلوبه وطريقة البيع |
| `app/agent.py` | عقل البوت والأدوات اللي بيستخدمها |
| `app/pricing.py` | حساب الأسعار والتفاوض (الحد الأدنى محمي بالكود) |
| `app/erp/` | مصدر السيارات وتسجيل طلبات الحجز |
| `app/whatsapp.py` | إرسال واستقبال رسائل واتساب |
| `app/notify.py` | الإشعارات |
| `app/main.py` | السيرفر: webhook واتساب + صفحة التجربة `/test` |
| `chat_cli.py` | تجربة البوت من الطرفية |

## التشغيل والتجربة (قبل الربط مع واتساب)

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

عبّي `.env`، وأهم شي فيه `ANTHROPIC_API_KEY` و`TEST_PAGE_PASSWORD`. بعدها:

```bash
uvicorn app.main:app --port 8000
```

افتح `http://localhost:8000/test`، اكتب كلمة السر، واحكي مع آدم كأنك زبون. الإشعارات بتظهر بنفس الصفحة بخلفية صفراء.

أو من الطرفية:

```bash
python chat_cli.py
```

## التدريب والتطوير

- **عقل آدم:** عدّل ملفات `knowledge/brain/`. أي شي بتكتبه هون آدم بيعرفه وبيتصرف على أساسه.
- **الأسعار:** عدّل `knowledge/fleet.yaml`، ولكل سيارة `min_daily_price` هو أقل سعر بيوصله التفاوض.
- لما يغلط آدم بمحادثة تجريبية، احكيلي شو كان لازم يقول ومنعدّل التدريب.

## الربط مع واتساب (Meta)

1. استضف السيرفر على رابط `https` دائم (Railway / Render / VPS). في `Dockerfile` جاهز.
2. بـ Meta for Developers ← تطبيقك ← WhatsApp ← Configuration:
   - Callback URL: `https://YOUR-DOMAIN/webhook`
   - Verify token: نفس قيمة `WHATSAPP_VERIFY_TOKEN`
   - اشترك بحقل `messages`
3. عبّي بـ `.env`: `WHATSAPP_TOKEN` (توكن دائم من System User)، `WHATSAPP_PHONE_NUMBER_ID`، `WHATSAPP_APP_SECRET`.

> ملاحظة: إشعارات واتساب للمدير بتوصل بس إذا المدير بعت رسالة لرقم البوت خلال آخر 24 ساعة (قاعدة من Meta).
> للإشعارات الدائمة استخدم `NOTIFY_WEBHOOK_URL`، أو منضيف Template معتمد من Meta.
