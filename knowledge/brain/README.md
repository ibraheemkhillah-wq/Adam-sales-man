# عقل آدم 🧠

كل ملف بهالمجلد آدم بيقرأه قبل كل رد. **أي تعديل هون = آدم بيتصرف على أساسه.**

- عدّل من GitHub مباشرة: افتح الملف ← أيقونة القلم ✏️ ← عدّل ← **Commit changes**.
- النص بين [أقواس مربعة] مسودة لازم تستبدلها بالمعلومة الحقيقية.
- اكتب بالعربي وبكلام بسيط، كأنك عم تشرح لموظف جديد.
- الملفات بتنقرأ بالترتيب حسب الرقم.
- هالملف (README) آدم ما بيقرأه، هو بس إلك.

| الملف | شو فيه |
|---|---|
| `01-identity.md` | شخصية آدم وأسلوبه ولغته |
| `02-company.md` | معلومات الشركة والشروط والخدمات |
| `03-sales-process.md` | خطوات البيع من أول رسالة لطلب الحجز |
| `04-negotiation.md` | أسلوب التفاوض (الأرقام نفسها بـ fleet.yaml و pricing.yaml) |
| `05-permissions.md` | الصلاحيات: شو بيقرر لحاله، شو بيرجع فيه للإدارة، شو ممنوع |
| `06-reply-map.md` | خريطة الردود: مواقف وأمثلة على الرد المثالي |
| `07-faq.md` | أسئلة متكررة وأجوبتها |
| `08-escalation.md` | متى وكيف بيحوّل للموظف |

### أشياء محمية بالكود (مش بس بالكلام)
هدول ما بيتغيروا من هون حتى لو انكتب عكسهم، لأنهم محميين بالبرمجة:
- آدم ما بيقدر ينزل تحت أقل سعر لكل سيارة.
- آدم ما بيعرف أقل سعر أصلاً، فما بيقدر يكشفه.
- الحجز دايماً "طلب" بينتظر تأكيد موظف.
